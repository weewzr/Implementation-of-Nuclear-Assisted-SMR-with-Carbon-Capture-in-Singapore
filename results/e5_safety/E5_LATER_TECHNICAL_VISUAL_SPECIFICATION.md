# E5 Later Technical Visual Specification

E5 quantitative-safety visuals must be deterministic technical graphics generated from canonical registers/models, not AI artwork.

1. **Screening event tree** — initiator -> trip/protection -> shutdown -> decay-heat removal -> isolation -> barrier state -> endpoint. Branches carry "probability not yet available" until PRA data exist.
2. **Mechanistic source-term chain** — core inventory -> TRISO release -> graphite/core retention -> primary-circuit deposition/dust -> confinement -> environmental release -> dispersion -> dose. Colour/tag each stage by DEMONSTRATED / MODELLED / PROJECT INPUT MISSING.
3. **Chemical QRA chain** — release source -> isolation -> rate/duration -> dispersion -> ignition/no ignition -> fire/explosion/toxic/asphyxiant effect -> escalation -> receptor/SSC fragility -> risk criterion.
4. **Integrated separation calculation chain** — scenario -> consequence contours -> nuclear SSC fragility -> required barrier/distance; explicitly no current numeric separation.
5. **Quantifiable-now maturity chart** — distinguish project-derived quantities, source measurements, parameterised equations, and blocked calculations.
6. **E5 programme/gate diagram** — inputs -> acquisition -> model -> output -> acceptance criterion -> design/site decision.

Never use AI-generated risk contours, event/fault trees, dose maps, F-N curves, blast contours or EPZ diagrams. AI artwork may later illustrate conceptual equipment/site context only and must not carry quantitative safety meaning.
