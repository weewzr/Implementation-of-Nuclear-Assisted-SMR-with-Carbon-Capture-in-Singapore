# E3 Later Visual Specification — Jurong Island Candidate Integration Context

## Purpose
This is a **data specification for later artwork**, not a site plan. No exact parcel, coordinates, nuclear site, exclusion radius or approved routing is implied.

## Required visual message
Title: **Jurong Island candidate industrial-integration context — conceptual, conditional, not to scale**

Show a coastal industrial context with five visually separated functional zones:

1. **Nuclear island (candidate only)**
   - one 600 MWth GTHTR300C-class reactor block;
   - primary-helium system retained inside nuclear boundary;
   - IHX/process-heat interface at boundary;
   - fuel/waste handling interface symbol;
   - independent safety/security perimeter;
   - label: "candidate nuclear island — site not selected or approved".

2. **Secondary-helium heat corridor**
   - two physically separate secondary-helium branches or an explicitly manifolded concept feeding two SMR trains;
   - total useful process heat = 353.6 MWth;
   - no primary reactor coolant entering chemical plant;
   - no electricity output/revenue label.

3. **Two H2 + CCS trains**
   - Train A and Train B, each: SMR → WGS → CO2 capture → PSA → H2;
   - each 130 MMSCFD H2; total 260 MMSCFD / ~195,892 t/y;
   - NG total 68 MMSCFD;
   - captured CO2 total ~1.085 Mt/y;
   - H2 product arrows to "industrial offtake/network — capacity to be secured", not a named customer.

4. **Cooling / water edge**
   - conceptual seawater intake and outfall OR seawater cooling tower option;
   - label both as alternatives, not selected design;
   - annotate "actual Q_reject unresolved";
   - optional small inset: illustrative full-power residual-disposition envelope 246.4 MWth → ~7.53 m3/s seawater at 8 K reference rise;
   - label explicitly "screen only — 246.4 MWth is not canonical cooling duty";
   - show coastal-protection/flood-resilience interface.

5. **CO2 logistics / port interface**
   - CO2 conditioning/compression → buffer/export interface → ship/pipeline icon → "cross-border storage — conditional/not contracted";
   - do not draw a specific foreign storage field as secured.

## Separation and hazards
- leave visible whitespace between nuclear island and H2/NG/CO2 chemical plant;
- label separation: "distance determined by QRA/PRA/consequence analysis — not fixed here";
- show nearby industrial context only generically: refinery/chemical/storage/pipeline/port icons;
- use hazard callouts: industrial fire/explosion/toxic release; marine/shipping; coastal flood/storm surge; common utility loss;
- do not draw an EPZ radius.
