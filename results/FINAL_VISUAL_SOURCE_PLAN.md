# Final Visual Source Plan

## Scope and rule

This plan identifies real base/reference images and editable layout templates only. It does **not** generate or integrate final visuals. Quantitative plots, event trees, risk/source-term chains and numerical roadmap gate labels remain deterministic.

The preferred visual workflow is: **real/authoritative base or existing user artwork -> scientifically constrained edit -> user external design/AI workflow -> upload -> scientific validation -> manuscript integration**.

- After the secondary-helium header, create **two parallel, visually equal process trains**.

- Make the secondary-He header/manifold visibly feed both reformers.

- Keep the nuclear and chemical sides visually distinct.

**FINAL CAPTION INTENT:** "Conceptual project-proposed mature architecture: one 600 MWth GTHTR300C-class source supplies two parallel 130 MMSCFD SMR-H2+CCS trains through an IHX/secondary-helium boundary. Project-derived configuration; not to scale and not a published JAEA/INL plant."

7. **No quantitative risk/economic graphics from AI:** risk contours, event trees, source-term chains, economics and abatement plots remain deterministic.
