# FINAL DESIGN ASSUMPTIONS

## Source-backed final process
- INL Case-6 HTGR-integrated SMR with carbon capture is the final process architecture.
- 871 C reformer outlet, S/C=3.0, 31.7 bar feed compression condition, 78.1% methane conversion and 88% PSA recovery.
- 925 C INL reactor outlet supplies 900 C process heat and eliminates the fired second reformer.
- 130 MMSCFD H2 product is retained as the source process scale before annualization.

## Hardware integration
- One 600 MWth GTHTR300C-class module is used because 176.8 MWth process heat is below reactor thermal capacity.
- The source 170 MWth JAEA IHX is slightly below the INL duty. Rather than pretending 170 MWth is adequate, the final economic baseline uses JAEA's doubled-IHX/secondary-loop cost sensitivity as a conservative proxy for the enlarged heat-transfer train.
- 585 C secondary return is a JAEA-anchored integration assumption for helium-flow screening, not an INL Case-6 reported value.

## Lifecycle
- Direct source CO2 values come from INL.
- Upstream NG = 11.5 gCO2e/MJ global source proxy.
- Nuclear heat lifecycle proxy = 5.5 gCO2e/kWh multiplied by the existing project heat/electric allocation convention.
- CCS transport burden = 2.5% of captured CO2 as an explicit project screening assumption.

## Economics
- Review-5 cost-year/FX methodology is retained.
- Full reactor heat+electricity economic burden is charged; net exported electricity is credited separately.
- Final baseline uses S$150/MWh electricity value with S$100 and S$200/MWh sensitivities.
- CCS T&S = S$15/t captured low screening scenario; Singapore tariff remains unresolved.
- 10% integration/site allowance remains a project screening assumption.

## Claim strength
The final result is a CONDITIONAL MODEL RESULT using source process balances plus project lifecycle/economic extensions. It is not an observed Singapore project cost or deployment forecast.
