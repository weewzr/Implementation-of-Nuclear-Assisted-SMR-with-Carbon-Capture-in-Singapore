## Provenance rule
Every numerical parameter adopted into the research model must be traceable to a cited primary paper, authoritative technical report, vendor technical document, or explicit model assumption. The supervisor's rendering repository establishes software provenance for the figure-generation environment, not scientific validation of the depicted process.
