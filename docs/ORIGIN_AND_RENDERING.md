# Design origin and rendering provenance

## Student-origin design

The project's initial figures were produced before this research reconstruction and show:

1. a conventional HTGR supplying steam to a turbine/generator for electricity, alongside a conventional fired steam-methane reformer with amine CO2 capture; and
2. a proposed HTGR-assisted configuration in which high-temperature helium supplies heat directly to the reformer and steam generator, removing the conventional reactor power-conversion path and the fired reformer furnace.

The attached student figure is treated as **design-origin evidence**. Its annotations and claims are not assumed to be scientifically validated.

## Rendering provenance

The student reports that the figure was produced by the supervisor using Rust code based on:

https://github.com/theodoreOnzGit/outram-park-backend

The repository is public, Rust-based, and describes OUTRAM PARK as an open-source transient multiphysics / advanced-reactor simulator backend. The workspace contains:
- a reusable digital-twin visualization engine;
- an HTGR educational simulator example (htgr_sim_v1);
- thermal-hydraulic and steam-generator related modules;
- heat-exchanger components and rendering backends;
- deterministic PNG/PDF/SVG figure-generation infrastructure.

Relevant files inspected during the project restart include:
- crates/outram-park-digital-twin-engine/examples/htgr_sim_v1/
- crates/outram-park-digital-twin-engine/examples/htgr_sim_v1/physics/steam_generator.rs
- crates/tampines/src/components/heat_exchanger.rs
- crates/tampines/src/components/steam_generator.rs
- crates/tampines-steam-tables/examples/tampines-steam-tables-gui/figure/png.rs
- crates/tampines-steam-tables/examples/tampines-steam-tables-gui/figure/svg.rs
- crates/tampines-steam-tables/examples/tampines-steam-tables-gui/figure/pdf.rs

## Important provenance limitation

Inspection of the public OUTRAM PARK repository did **not** identify a file whose search results explicitly contains the exact labels or process diagram shown in the student's attached HTGR/SMR/CCS figure. Therefore this document does not claim that the exact figure was generated by a specific source file in that repository.

What is established is narrower:
- the supervisor's stated rendering basis is the OUTRAM PARK Rust repository;
- the repository contains Rust HTGR simulation and deterministic scientific-figure infrastructure;
- the exact source program for the displayed figure remains unidentified from the public repository search.

## Research use

The figure will be retained as the historical origin of the proposed architecture. It will not be used as validation evidence.

Where the research model later reproduces or modifies the architecture, the computational diagram should be generated from the research model's own data and state so that process connections, temperatures, duties, flow rates, and labels are reproducible.
