# CN4252 Assignment Requirements

## Authority

The official CN4252 Problem Statement is authoritative for assignment requirements. The Project Brief is a candidate research direction and does not override the problem statement.

## Requirements matrix

| Requirement | Authoritative requirement | Consequence for this project |
|---|---|---|
| Objective | Propose a solution-at-scale capable of reducing emissions within Singapore | The research must establish actual annual abatement, not merely process efficiency |
| Abatement target | >0.25 MtCO2e/year | Required scale must be calculated explicitly |
| Cost target | <S$100/tCO2e | Must calculate abatement cost on an explicit basis |
| Solution freedom | Solution may be technology, deployment, or policy | Nuclear-assisted SMR is one candidate among alternatives |
| Originality | May be inspired by lectures/independent research but should not be a regurgitation of an existing Singapore project | Existing Singapore SMR+CCS work must be reviewed and the incremental novelty clearly demonstrated |
| Effectiveness | Must clearly show how the solution abates emissions | Need a baseline, counterfactual, emissions ledger, and annual scaling calculation |
| Implementation | Must clearly show an implementation roadmap | Technical design alone is insufficient |
| Assessment | Feasibility, potential effectiveness, content accuracy, presentation delivery | Feasibility and evidence quality are central outputs |
| Explicit assumptions | Problem Statement does not specify a unique technology, reactor, feedstock, capture solvent, or modelling tool | These remain open research decisions |
| Explicit system boundary | Problem Statement does not prescribe a detailed LCA boundary | Boundary must be selected, justified, and applied consistently |
| Explicit evaluation formula | Problem Statement gives thresholds but no prescribed abatement-cost equation | Define and justify a transparent abatement-cost method |

## Does the proposed concept answer the assignment?

**Yes, conditionally.**

HTGR-assisted SMR + amine CCS is capable in principle of being framed as a solution-at-scale because it can be evaluated for annual CO2e abatement and cost within Singapore.

However, the original concept is not yet an adequate assignment answer because the initial material does not yet demonstrate:
- >0.25 MtCO2e/year at actual production scale;
- <S$100/tCO2e;
- a full emissions counterfactual;
- lifecycle treatment of upstream methane emissions;
- complete CCS transport/storage accounting;
- the marginal benefit of nuclear integration relative to SMR+CCS alone;
- comparison with non-nuclear alternatives;
- Singapore-specific implementation and regulatory feasibility; or
- novelty relative to existing Singapore low-carbon hydrogen/CCS initiatives.

## Immediate assignment-risk findings

Singapore already has published work describing SMR hydrogen with amine CO2 capture, and in 2025 Aster and Air Liquide announced an MOU to assess an ATR process with integrated carbon capture on Jurong Island. Therefore, a generic "natural gas reforming + CCS in Singapore" proposal risks failing the originality requirement. The differentiating research question should be the value and feasibility of **HTGR heat integration** and its alternatives, not CCS alone.

## Scale implication

Using the IEA's reported 10-12 kgCO2e/kgH2 range for unabated natural-gas hydrogen, the absolute theoretical upper-bound scale corresponding to 0.25 MtCO2e/y is roughly 20.8-25 ktH2/y if all of those emissions were avoided. Actual required production will be higher whenever only part of lifecycle emissions are avoided.

This is a screening calculation, not a project result.

## Open design choices

- reactor technology and temperature grade
- direct versus indirect heat coupling
- heat/electricity allocation
- SMR configuration
- capture location(s)
- solvent
- hydrogen purification
- CO2 compression and transport
- storage/utilisation pathway
- lifecycle boundary
- economic assumptions
- deployment scale and location
