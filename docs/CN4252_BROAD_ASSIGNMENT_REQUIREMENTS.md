# CN4252 Broad Assignment Requirements — Midterm/Project Framing

## Source

User-provided CN4252 Midterm Assignment slide.

The slide gives the broad project/proposal framing and should be used together with, not instead of, the authoritative final CN4252 problem statement in `docs/CN4252_PROBLEM_STATEMENT.md`.

## Broad required content

The suggested proposal outline (1–2 pages) contains:

1. **Group members**
2. **Title**
3. **Decarbonisation problem and context**
4. **Proposed solution**, including:
   - preliminary abatement potential; and
   - preliminary cost estimates
5. **Key questions for further work**

Administrative midterm details shown on the slide (deadline, Canvas grouping/submission mechanics) are historical course administration and are not scientific manuscript requirements unless separately confirmed for the final submission.

## Consequence for the final research/manuscript

The final project should preserve this simple assignment spine even though the research has become much deeper:

**Decarbonisation problem/context
→ proposed solution
→ abatement potential
→ cost
→ feasibility/effectiveness
→ implementation
→ unresolved questions/further work.**

The technical report must not become so detailed that these original questions are difficult for the marker to locate.

### Decarbonisation problem and context

The manuscript/presentation should state clearly:
- what Singapore decarbonisation problem is being addressed;
- why conventional SMR-H2 creates emissions;
- why hydrogen/industrial heat matters to the chosen context;
- why Singapore-specific infrastructure/regulatory conditions matter.

### Proposed solution

The proposed solution should be explainable before detailed equations:
- HTGR-class high-temperature nuclear process heat;
- SMR-H2 chemical pathway;
- amine-based CO2 capture;
- conditional CO2 conditioning/transport/storage;
- physical separation of nuclear primary helium, secondary process-heat helium and chemical process gas.

### Abatement potential

The final work should progress from the midterm notion of a preliminary estimate to a transparent final calculation:
- baseline/counterfactual;
- direct emissions;
- captured versus avoided CO2;
- lifecycle additions/subtractions;
- annualisation;
- final tCO2e/y;
- comparison with the official >0.25 MtCO2e/y threshold;
- sensitivity/robustness and what portion is attributable to CCS versus nuclear heat.

### Cost estimate

The final work should progress from a preliminary estimate to the strongest defensible engineering-economic model supported by available data:
- explicit cost boundary;
- CAPEX/OPEX treatment;
- cost-year/currency normalization;
- annualisation;
- avoided-emissions denominator;
- final S$/tCO2e;
- comparison with the official <S$100/tCO2e threshold;
- clear distinction between screening estimates and bankable/project-level economics.

The historical S$3.725/tCO2e differential screening bridge remains repository provenance but should not control the final report if the post-screening engineering-economic workflow produces a stronger result.

### Key questions / further work

The final manuscript should explicitly preserve unresolved questions rather than hiding them.

These include where still unresolved:
- project-scale IHX qualification;
- integrated reactor/process transients;
- nuclear/chemical safety and QRA;
- mechanistic source term/PRA/EPZ;
- Jurong Island/candidate-site feasibility;
- cooling/heat rejection;
- tritium/radiological classification;
- cross-border CCS capacity/storage;
- FOAK/project economics;
- licensing/regulatory readiness.

## Relationship to final CN4252 requirements

The later official problem statement additionally requires:
- solution-at-scale within Singapore;
- >0.25 MtCO2e/y;
- <S$100/tCO2e;
- clear abatement mechanism;
- implementation roadmap;
- originality;
- feasibility;
- potential effectiveness;
- content accuracy;
- presentation delivery.

Both requirement sets therefore apply as complementary framing:

**Broad assignment spine:** problem/context → solution → abatement → cost → questions.

**Final evaluation spine:** scale/thresholds → feasibility/effectiveness → implementation → originality/accuracy/presentation.

## Required traceability

Future manuscript, engineering-closure and presentation work should be able to point to where each broad item is answered.

Do not allow detailed nuclear modelling, costing or safety work to obscure the simple top-level assignment answer.
