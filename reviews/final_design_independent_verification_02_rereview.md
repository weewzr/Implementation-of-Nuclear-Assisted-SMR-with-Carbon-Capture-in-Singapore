## FDV2-M02 — NOT RESOLVED

### Corrected heat branch
The corrected code explicitly writes:

600 = 176.8 + 423.2 MWth.

That arithmetic thermal split closes at the reactor-rating level.

The process-side helium screen also improves materially:
- supply = 900 C;
- return = 466 C;
- Cp = 5.2 kJ/kg-K;
- Q = 176.8 MW.

Independent constant-Cp reconstruction:

m_dot = 176800 / [5.2(900-466)]
= **78.34 kg/s**,

within about 0.2% of INL Case-6's 78.49 kg/s.

This portion is acceptable as an explicitly labelled screening approximation.

### Power-cycle mapping remains unverified
The project derives:

eta = 88 / (600-370) = 88/230 = 0.38261,

then applies that same ratio to:

423.2 MWth residual thermal power,

giving:

P_gross = 423.2(88/230)
= **161.92 MWe**.

It then subtracts only the INL process demand:

P_net = 161.92 - 17.3
= **144.62 MWe**,

and annualizes this as:

144.62(7446)
= **1,076,840.52 MWh/y**.

This is transparent, but transparency alone does not satisfy the original
acceptance criterion.

Two independent problems remain:

1. **No source-backed part-load conversion model.**
   Nishihara's 88 MW belongs to the source 370-MW IHX / 230-MW residual thermal
   split. The repository provides no turbine-cycle calculation or primary
   evidence that 38.26% gross conversion remains constant when the residual
   thermal branch increases to 423.2 MWth. The source gas-turbine inlet
   temperature is 730 C and the primary-loop state changes with the heat split;
   linear scaling is therefore a project screening assumption, not a verified
   integrated power-cycle solution.

2. **Reactor-system electrical consumption is omitted from net export.**
   Nishihara states that the 88 MW generated by the gas turbine is used in the
   **reactor system and IS process**. The corrected project treats the derived
   161.92 MWe as gross generation and subtracts only the 17.3 MWe INL chemical
   process demand. It does not quantify or subtract JAEA reactor-system
   internal electrical demand. Therefore 144.62 MWe is not demonstrated to be
   net export.

The original FDV2-M02 acceptance criterion required process heat, helium state,
residual power-cycle heat and gross MWe to form one mutually energy-consistent
plant. That criterion is not yet satisfied.

### Decision
**FDV2-M02 — NOT RESOLVED.**

A valid correction needs either a source-supported GTHTR300C heat/power split
for the 176.8-MW heat draw or an explicit thermodynamic power-cycle model,
including reactor-system internal electrical consumption, before net export is
credited.
