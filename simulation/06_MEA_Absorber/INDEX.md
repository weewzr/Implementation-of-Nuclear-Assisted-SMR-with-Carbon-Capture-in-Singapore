# 06_MEA_Absorber

Scope: MEA absorber data and validation (pilot plants, rate-based models).

Papers in this folder: 3. Page numbers marked PDF are PDF page numbers; printed means the page number printed on the document.

Folder note: The main MEA models and parameter sources are filed under 05. Morgan et al. also covers the stripper (see 07).

- DOI or official URL: https://doi.org/10.1021/acs.iecr.8b01472

- Primary engineering purpose: Validation_Data
- Secondary engineering uses: Experimental_Data
- Equipment supported: MEA absorber; MEA stripper; reboiler duty
- Equations: Partial. Literature parameter values: Partial. Validation data: Yes.

- Notes: Complete (18 pp). Also supports folder 07 (stripper).
